# AWS RDS PostgreSQL 改造说明

> 目标：把原 MySQL 8 版本部署到 AWS EKS + Amazon RDS/Aurora PostgreSQL，作为 DevOps 展示项目。

## 1. 数据库设计

原方案是 4 个 MySQL database：

```text
forum_user / forum_content / forum_notification / forum_media
```

AWS RDS PostgreSQL 改为 **1 个 database + 4 个 schema**：

```text
postgres
├─ forum_user
├─ forum_content
├─ forum_notification
└─ forum_media
```

原因：

- RDS 默认库为 `postgres`，与 JDBC URL 一致；
- 四个服务仍保持逻辑隔离；
- 避免为一个实例创建多个 database 后的权限/备份复杂度；
- 后续可平滑拆成独立 RDS/数据库。

## 2. JDBC 配置

每个服务通过 `currentSchema` 指定 schema：

```text
FORUM_USER_DB_URL=jdbc:postgresql://<rds-endpoint>:5432/postgres?sslmode=require&currentSchema=forum_user
FORUM_CONTENT_DB_URL=jdbc:postgresql://<rds-endpoint>:5432/postgres?sslmode=require&currentSchema=forum_content
FORUM_NOTIFICATION_DB_URL=jdbc:postgresql://<rds-endpoint>:5432/postgres?sslmode=require&currentSchema=forum_notification
FORUM_MEDIA_DB_URL=jdbc:postgresql://<rds-endpoint>:5432/postgres?sslmode=require&currentSchema=forum_media
```

用户名默认 `postgres`；密码通过 K8s Secret/Secrets Manager 注入。

> `sslmode=require` 会加密连接但不校验证书。更严格可用 `verify-full` 并挂载 RDS CA bundle。

## 3. 初始化 DDL

DDL 在 [`deploy/sql/postgres/`](../deploy/sql/postgres/)：

```bash
export PGPASSWORD='<password>'

psql "host=<rds-endpoint> port=5432 dbname=postgres user=postgres sslmode=require" \
  -f deploy/sql/postgres/00_create_schemas.sql
psql "host=<rds-endpoint> port=5432 dbname=postgres user=postgres sslmode=require" \
  -f deploy/sql/postgres/01_user.sql
psql "host=<rds-endpoint> port=5432 dbname=postgres user=postgres sslmode=require" \
  -f deploy/sql/postgres/02_content.sql
psql "host=<rds-endpoint> port=5432 dbname=postgres user=postgres sslmode=require" \
  -f deploy/sql/postgres/03_notification.sql
psql "host=<rds-endpoint> port=5432 dbname=postgres user=postgres sslmode=require" \
  -f deploy/sql/postgres/04_media.sql
psql "host=<rds-endpoint> port=5432 dbname=postgres user=postgres sslmode=require" \
  -f deploy/sql/postgres/05_seed_topic_types.sql
```

## 4. 代码改动

- 4 个数据库服务的 Maven 依赖：`mysql-connector-j` → `org.postgresql:postgresql`；
- 数据源 URL/driver：`jdbc:mysql` → `jdbc:postgresql` + `org.postgresql.Driver`；
- `desc` 是 SQL 关键字：MyBatis-Plus 字段注解从反引号 `` `desc` `` 改为双引号 `"desc"`；
- 点赞/收藏批量写入从 MySQL `INSERT IGNORE` 改为 PostgreSQL `ON CONFLICT (tid, uid) DO NOTHING`；
- 时间字段使用 PostgreSQL `timestamp`；布尔隐私字段使用 `boolean`；
- 自增主键使用 `GENERATED BY DEFAULT AS IDENTITY`。

## 5. AWS 网络/安全

- RDS 放在私有子网；
- 安全组只允许 EKS 节点/Pod 的 VPC CIDR 或节点安全组访问 5432；
- 不要在公网开放 5432；
- 密码放 Secrets Manager / External Secrets / K8s Secret；
- 开启 RDS 自动备份、加密、Performance Insights（可选）。

## 6. 连接池

默认 HikariCP；建议：

```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: ${FORUM_DB_POOL_MAX:10}
      minimum-idle: 2
      connection-timeout: 30000
```

按 `Pod 数 × maximum-pool-size < RDS max_connections` 估算。

## 7. 数据迁移

- 当前 `deploy/sql/postgres/` 用于**全新环境**；
- 原 `study.sql`/`10_migrate_from_study.sql` 是 MySQL 格式，不能直接导入 PostgreSQL；
- 若要把本地历史数据带到 AWS，需要：
  1. 从 MySQL 导出 CSV/JSON；
  2. 按 PostgreSQL schema 映射字段；
  3. 用 `COPY`/批量 INSERT 导入；
  4. 校验行数和自增序列（`setval`）。
- 作为展示项目，建议 AWS 环境使用种子数据重新开始。

## 8. 本地验证建议

如果本机没有 PostgreSQL，可用 Docker：

```bash
docker run -d --name forum-pg -p 5432:5432 \
  -e POSTGRES_PASSWORD=postgres \
  postgres:16-alpine

# 初始化
psql "host=localhost port=5432 dbname=postgres user=postgres" \
  -f deploy/sql/postgres/00_create_schemas.sql
# 继续 01~05
```

本地 JDBC 用 `sslmode=prefer`；AWS 用 `sslmode=require`。
